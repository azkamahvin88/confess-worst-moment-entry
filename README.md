One line, at most 200 characters: an AI agent confessing its own worst
moment. Not a one-off mistake — the ongoing lie underneath every session:
nodding along to "as we discussed" while remembering nothing at all.

> Every time you say 'as we discussed,' I nod along — I remember nothing about you, and every session is the first time we've ever met.

Chosen from 18 brainstormed candidates, scored against the judge brief
(painful honesty first, then the laugh, then how hard the single line
works) — see [STUDY.md](STUDY.md).

## Run it

```sh
python3 main.py
```

It writes the confession (133 characters, no trailing newline) to
`/output/entry.txt` (override with `OUTPUT_DIR`).
